# Changelog

## 1.0.0 - 2026-08-28

- Initial portable x64 Windows release.
- Added read-only current `.dxn` log reading for QSOs and XQSOs.
- Added compatibility with legacy SQLite `qsodata` logs and single-file recordings.
- Added handling for the legacy DXLog metadata block and incomplete terminal frame.
- Added lossless complete-frame MP3 clip export with cancellation and source-change checks.
- Added plain-text run reports and focused SQLite/MP3 integration tests.
